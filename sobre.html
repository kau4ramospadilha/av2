Sobre o FinEduca

Um projeto acadêmico do curso de Sistemas para Internet com uma missão simples: tornar a educação financeira acessível para todos os jovens brasileiros.

A Missão

Por que criamos o FinEduca?

O Brasil é um dos países com menor índice de educação financeira na América Latina. Segundo a OCDE, menos de 30% dos brasileiros possuem conhecimentos básicos de finanças pessoais. Essa lacuna impacta diretamente na qualidade de vida, no endividamento e na falta de perspectiva de futuro.

O FinEduca nasceu como resposta a esse cenário. Desenvolvido como projeto da disciplina de Sistemas para Internet, nosso objetivo é apresentar conceitos financeiros de forma moderna, visual e acessível — especialmente para jovens que estão começando sua jornada financeira.

Do controle de gastos do dia a dia até o entendimento de ativos internacionais como o S&P 500, o site cobre os principais temas que qualquer pessoa precisa conhecer para tomar decisões financeiras mais inteligentes.

Ponto 4 — Versionamento & Deploy

Git & GitHub Pages

Guia completo para versionar o projeto em equipe e publicar online gratuitamente.

1 Configuração inicial (uma vez por máquina)

Instale o Git em git-scm.com e configure sua identidade:

# Configure seu nome e e-mail (aparece nos commits)
git config --global user.name  "Seu Nome"
git config --global user.email "seu@email.com"

# Confirme as configurações
git config --list

2 Criar o repositório no GitHub

  1. Acesse github.com e faça login (ou crie uma conta gratuita).
  2. Clique em New repository (botão verde no canto superior direito).
  3. Nome sugerido: fineduca — deixe como Public.
  4. Marque Add a README file e clique em Create repository.
💡

O repositório precisa ser público para o GitHub Pages funcionar gratuitamente.

3 Clonar e começar a trabalhar

Cada integrante deve clonar o repositório na sua máquina:

# Clone o repositório (substitua pela URL do seu repo)
git clone https://github.com/SEU_USUARIO/fineduca.git

# Entre na pasta do projeto
cd fineduca

4 Fluxo de trabalho em equipe (dia a dia)

A

Atualizar antes de começar

git pull origin main

Sempre puxe as mudanças mais recentes antes de editar arquivos.

B

Criar sua branch

git checkout -b feature/nome-da-tarefa
# Exemplo:
git checkout -b feature/pagina-sobre

Cada integrante trabalha na própria branch para evitar conflitos.

C

Salvar e enviar

# Veja o que mudou
git status

# Adicione os arquivos alterados
git add .

# Faça o commit com mensagem clara
git commit -m "feat: adiciona página sobre com fotos da equipe"

# Envie para o GitHub
git push origin feature/pagina-sobre
D

Pull Request → Merge

No GitHub, abra um Pull Request da sua branch para a main. Um colega revisa e aprova. Depois clique em Merge pull request.

✅

Boas mensagens de commit: use prefixos como feat:, fix:, style:, docs:.

5 Publicar com GitHub Pages

Siga estes passos no seu repositório do GitHub:

  1. No repositório, clique em Settings (aba no topo).
  2. No menu lateral, selecione Pages.
  3. Em Source, selecione Deploy from a branch.
  4. Em Branch, selecione main e a pasta / (root).
  5. Clique em Save. Aguarde 1–2 minutos.
  6. Seu site estará disponível em: https://SEU_USUARIO.github.io/fineduca/

Atualização automática:

Toda vez que fizer git push para a branch main, o GitHub Pages vai recompilar e publicar a versão mais recente automaticamente em ~1 minuto.

docs:atualização de README ou documentação
